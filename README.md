# 🎨 Leon Website

A clean, minimal, and fully responsive **creative agency landing page** built using pure **HTML5** and **CSS3**.  
The project focuses on modern layout techniques, responsiveness, and elegant UI design.

---

## ✨ Features

- 📱 Fully Responsive Design (Mobile, Tablet, Desktop)
- 🎨 Minimal & Modern UI
- 🧭 Smooth Scrolling Navigation
- 🍔 Mobile Friendly Toggle Menu
- 🗂️ Multiple Sections:
  - Home
  - Features
  - Services
  - Portfolio
  - About
  - Contact
- 🖼️ Portfolio Grid Layout
- 🎯 CSS Variables for easy customization
- 🧩 Reusable Global Components
- 🌐 Social Media Links

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **CSS Grid & Flexbox**
- **Font Awesome**
- **Google Fonts (Work Sans)**
- **Normalize.css**
